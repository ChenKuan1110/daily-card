给 agent 用的接口

后台所有能力都有对应 JSON 接口，完整说明见项目内 SKILL.md。

curl -s http://127.0.0.1:8777/api/render \
  -H 'Content-Type: application/json' \
  -d '{"title":"今天也要好好生活","subtitle":"把日子过得响亮一点"}'
常用接口
  • GET /api/bootstrap 读取主题 / 贴纸 / 设置 / 平台
  • POST /api/render 生成预览，返回 PNG base64
  • POST /api/save 生成并写入 output 目录
  • POST /api/theme-preview 未保存主题草案 → 卡片 / 语义图 / 诊断
  • POST /api/schemes 背景图 → 多套配色方案
  • POST /api/config/themes 保存主题配置
  • POST /api/config/settings 保存全局设置
  • POST /api/config/reset 恢复出厂主题
  • GET /api/sticker?id=book 贴纸图标 PNG

也可以完全绕开后台，直接用 python3 cardgen.py 命令行生成。
